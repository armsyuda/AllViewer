# 다뷰 (AllViewer)

### 프로그램 하나로 문서·이미지·동영상을 봅니다

문서, 사진, 동영상은 보통 종류마다 다른 프로그램이나 뷰어를 설치해서 엽니다.
다뷰는 이 기능들을 한 프로그램에 모았습니다. 하나만 설치하면 문서·시트·슬라이드·PDF·이미지·동영상을 한 창에서 볼 수 있습니다.
한컴오피스나 Microsoft Office 같은 원본 앱이 없어도 됩니다.

유료 구독은 없습니다. 무료로 쓸 수 있습니다.

[**0.3.6 내려받기**](https://github.com/armsyuda/AllViewer/releases/download/v0.3.6/AllViewer_0.3.6_x64-setup.exe)

[0.3.6 릴리스 페이지](https://github.com/armsyuda/AllViewer/releases/tag/v0.3.6)에서 바뀐 내용을 볼 수 있습니다.

## 지원 형식

| 종류 | 형식 | 할 수 있는 것 |
|---|---|---|
| 한글 | HWP, HWPX | 보기, 글자 선택·복사, 찾기, 사본 편집. 한컴 프로그램 설치 필요 없음 |
| 엑셀·시트 | XLSX, XLS, CSV, 다뷰 시트(.avsheet)·템플릿(.avtemplate) | 보기와 간단한 편집, PDF로 출력 |
| 파워포인트 | PPTX, PPT | 보기, 썸네일 이동, 사본 편집 |
| 워드 | DOCX, DOC | 보기, 썸네일 이동, 사본 편집 |
| PDF | PDF | 보기, 페이지 삭제·회전·순서 바꾸기·합치기, 이미지(PNG/JPEG)로 내보내기, 암호 PDF 열기 |
| 이미지 | PNG, JPG/JPEG, WebP, BMP, GIF, TIF/TIFF, HEIC/HEIF, AVIF | 확대·축소, 보기 회전, 같은 폴더 사진 ←/→ 넘기기, 50MB 넘는 큰 사진도 열기 |
| 동영상 | MP4, WebM, MKV | 재생 |
| 음악 | MP3, WAV, M4A, AAC, OGG, OPUS | 재생 |

- WMV·AVI 동영상은 재생되지 않습니다. 열면 재생할 수 없다는 안내가 나옵니다.
- HEVC(H.265) 영상은 Microsoft Store의 'HEVC 비디오 확장'을 설치해야 재생됩니다. 확장이 없는 PC에서 나오는 안내는 아래 '알려진 문제'를 보세요.

## 주요 기능

- **한 창, 여러 탭** — 종류가 다른 파일도 탭으로 나란히 엽니다. 탭을 창 밖으로 끌면 새 창이 됩니다.
- **트레이에서 미리 준비** — 컴퓨터를 켤 때 다뷰가 작업 표시줄 오른쪽 아래(트레이)에서 미리 준비합니다. 문서를 더블클릭하면 바로 열립니다. 설정에서 끌 수 있습니다.
- **원본은 그대로** — 고친 내용은 사본으로 따로 저장합니다. 원본 파일을 덮어쓰지 않습니다.
  - 시트(XLSX·XLS·CSV)는 다뷰 시트나 XLSX로 따로 저장합니다.
  - PDF 페이지 작업은 새 PDF로 저장합니다.
  - 한글·워드·파워포인트는 사본을 고칩니다. 원본 파일은 바뀌지 않습니다.
    - 고칠 수 있는 것: 글자, 이미지, 맞춤(정렬), 쪽 번호, 글꼴, 슬라이드, 표
    - 사본은 `원래이름_수정본`으로 저장합니다. 한글 사본은 HWPX로, 구형 형식은 HWPX 또는 DOCX 사본으로 저장합니다.
    - 가장 많이 쓰는 기능만 간단히 넣었고, 한글·워드·파워포인트의 모든 편집 기능이 있는 것은 아닙니다.
- **글자 뽑기(OCR)** — 스캔한 PDF나 사진 속 글자도 인식해 복사·검색합니다. 인터넷 없이 내 PC 안에서 처리합니다.
- **글꼴 대체·원본 이미지 꺼내기** — 없는 글꼴을 다른 글꼴로 바꿔 보고, 문서 속 그림을 원래 화질로 저장합니다.
- **자동 업데이트** — 새 버전이 나오면 창 위쪽(제목표시줄) 아이콘 색이 바뀌어 알려 줍니다. 아이콘을 누르면 바뀐 내용을 보고 바로 업데이트할 수 있고, 설치 후 열던 문서와 탭을 되살립니다.
- **복구** — 갑자기 꺼져도 저장하지 않은 시트·PDF 작업을 다시 불러옵니다.

## 단축키

| 키 | 하는 일 |
|---|---|
| Ctrl+O | 파일 열기 |
| Ctrl+F | 찾기 |
| Ctrl+마우스 휠 | 확대·축소 |
| Ctrl+, | 설정·단축키 |
| ← / → | 같은 폴더의 이전·다음 사진 |
| Tab | 사진 집중 보기 ↔ 일반 보기 |
| F2 | 시트 셀 편집 |

단축키는 **설정 · 단축키**에서 바꿀 수 있습니다.

## 설치 방법

1. 위의 **0.3.6 내려받기**를 누릅니다.
2. 설치 파일 `AllViewer_0.3.6_x64-setup.exe`를 받습니다.
3. 받은 파일을 실행합니다.
   - 설치 파일에 코드 서명이 없어 처음 실행할 때 'Windows의 PC 보호' 경고가 뜰 수 있습니다. 이때 **추가 정보 → 실행**을 누르세요.
4. 설치 중 **'컴퓨터 시작 시 트레이에서 준비'**를 고릅니다. (기본: 켜짐)
5. 설치가 끝나면 다뷰를 기본 앱으로 지정할지 묻습니다. 최종 선택은 Windows 설정에서 합니다.

이미 다뷰를 쓰고 있다면 앱이 새 버전을 알려 줍니다. **업데이트**만 누르세요.

## 시스템 요구 사항

| 항목 | 내용 |
|---|---|
| 운영체제 | Windows 10(64비트) 이상 |
| 화면 엔진 | Microsoft Edge WebView2. 없으면 설치 프로그램이 받아서 설치합니다 |
| 인터넷 | WebView2가 없는 PC는 처음 설치할 때만 필요. 설치 뒤 문서 보기·OCR은 인터넷 없이 됩니다 |
| 따로 설치할 것 | 없음 (한컴오피스·Microsoft Office·Python 등 필요 없음) |
| 설치 파일 크기 | 약 163MB (170,786,619바이트) |

## 알려진 문제 (0.3.6)

- 동영상이 재생되자마자 한 번 멈추던 문제는 0.3.5에서 고쳤고 시험에서는 다시 나오지 않았습니다. 다만 여러 PC에서 충분히 확인하지는 못했습니다.
- HEVC 확장이 없는 PC에서 HEVC 영상을 열 때 나오는 안내는 아직 직접 확인하지 못했습니다.

다뷰는 여러 오픈소스 부품을 사용합니다. 설치 파일 안의 `licenses` 폴더에 사용한 오픈소스 목록과 각 라이선스 글이 들어 있습니다.

| 부품 | 쓰는 곳 | 라이선스 |
|---|---|---|
| Tauri | 앱 틀 | MIT 또는 Apache-2.0 |
| pdf.js | PDF 표시 | Apache-2.0 |
| rhwp (수정본) | 한글(HWP/HWPX) 읽기 | MIT |
| rdocx·oxml-layout·rpptx (수정본) | 워드·파워포인트 읽기 | MIT 또는 Apache-2.0 |
| LibreOffice 26.8.1.1 (일부) | 구형 문서 변환 | MPL-2.0 (함께 든 부품 포함) |
| hayro-syntax | PDF 처리 | Apache-2.0 또는 MIT |
| RTen + PaddleOCR PP-OCRv5 모델 | 글자 인식(OCR) | MIT·Apache-2.0 / Apache-2.0 |
| Noto Sans KR 등 글꼴 | 문서 표시 | OFL-1.1 |
| 그 밖의 Rust 부품 | 여러 기능 | 대부분 MIT, Apache-2.0, BSD 등 (일부 MPL-2.0) |

- 동영상·소리 코덱은 앱에 넣지 않았습니다. 재생은 WebView2(Edge)와 Windows가 맡습니다.
- 한컴의 DLL·SDK·글꼴은 쓰지 않습니다.
- 본 제품은 한컴의 HWP 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.
- 다뷰는 무료로 쓸 수 있습니다. 다만 다뷰를 고치거나, 다시 배포하거나, 판매하는 것은 허용하지 않습니다. 자세한 내용은 [LICENSE](LICENSE) 파일을 보세요.
- 오픈소스 부품은 각자의 라이선스를 따릅니다(설치 폴더의 `licenses` 폴더 참고).
