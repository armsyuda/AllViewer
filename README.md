# AllViewer · 다뷰

Windows용 통합 문서·이미지 뷰어입니다. 문서를 탭으로 열어 보고, PDF 페이지 정리와 기본 시트 편집을 할 수 있습니다.

## 다운로드

[최신 Windows x64 설치 파일](https://github.com/armsyuda/AllViewer/releases/latest)

- PDF, DOC/DOCX, PPT/PPTX, HWP/HWPX
- XLSX, XLS, CSV, AVSHEET/AVTEMPLATE
- PNG, JPG/JPEG, WEBP, BMP, GIF, TIF/TIFF, HEIC/HEIF, AVIF

## 업데이트

0.3.0부터 새 버전을 알리고, 사용자가 업데이트를 선택하면 서명을 확인한 뒤 설치·재실행합니다. 미저장 문서는 저장 또는 취소할 수 있습니다. 이전 버전 사용자는 업데이트 지원 설치본을 한 번 직접 설치해 주세요.

WebView2가 없으면 최초 설치 중 Microsoft 설치 도구를 다운로드하므로 인터넷 연결이 필요합니다. 설치 후 문서 열람과 OCR은 로컬에서 동작합니다.

형식별 표시·편집 호환성에는 제한이 있습니다. 오픈소스 구성요소 안내는 앱 설정에서 확인할 수 있습니다. 모든 파일의 동일한 표시나 로딩 시간을 보장하지 않습니다.
